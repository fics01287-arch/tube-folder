유튜브 영상을 내 컴퓨터 폴더처럼

튜브폴더는 유튜브·유튜브뮤직 영상을 원하는 만큼 하위 폴더를 만들어 정리하는 Chrome 확장 프로그램입니다.

📁 무제한 하위 폴더

내 컴퓨터 탐색기처럼 폴더 안에 폴더를 만들어 영상을 섹터별로 정리합니다.

🖱️ 우클릭으로 바로 관리

유튜브 페이지를 벗어나지 않고 우클릭 메뉴에서 폴더 생성·이름변경·삭제까지.

📥 재생목록 일괄 가져오기

재생목록 URL만 붙여넣으면 안에 있는 영상을 한 번에 폴더로 가져옵니다.

▶️ 이어보기

보던 영상은 멈춘 지점부터 자동으로 이어서 재생됩니다.

🗑️ 휴지통

삭제해도 바로 사라지지 않고 보관기간(기본 30일) 동안 복구할 수 있습니다.

☁️ 기기 간 동기화 (PRO)

구글 드라이브를 통해 PC·휴대폰에서 같은 폴더 구성을 이용합니다.
